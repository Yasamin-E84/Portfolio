Frontend Development

I specialize in building clean, responsive, and performant user interfaces using HTML, CSS, and vanilla JavaScript. My focus is on creating accessible, semantic code that works beautifully across all devices. I believe in mastering the fundamentals before moving to frameworks, which is why I'm building strong foundations in core web technologies.

My Approach

  • Semantic HTML: Writing clean, accessible markup that makes sense to both browsers and screen readers.
  • Modern CSS: Using CSS Grid, Flexbox, and custom properties to create flexible, maintainable layouts.
  • Vanilla JavaScript: Building interactive experiences with pure JavaScript, focusing on performance and maintainability.
  • Responsive Design: Ensuring every interface works flawlessly on desktop, tablet, and mobile devices.
  • Performance First: Optimizing for speed, accessibility, and user experience above all else.

Frequently Asked Questions

What's your preferred workflow?
I prefer a clean, component-like approach even with vanilla JavaScript. I organize code into modules, use semantic HTML, and maintain a consistent CSS architecture (similar to BEM methodology) for scalability.
Do you work with design tools?
Yes, I'm familiar with design fundamentals and use tools like Figma for understanding designs. I also work with Photoshop and Illustrator for creating assets and graphics.
