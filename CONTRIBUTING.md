# Contributing

Use Node.js 22 or newer and install with `npm ci`. Create a focused branch, keep secrets in ignored environment files, and never commit private client assets or raw visitor data.

Before opening a change, run:

```sh
npm run typecheck
npm run lint
npm test
npm run build
```

Content changes must follow [`docs/EDITORIAL_GUIDE.md`](docs/EDITORIAL_GUIDE.md). Preserve English and Persian routes, keyboard access, reduced-motion behavior and the paper notebook visual language.
