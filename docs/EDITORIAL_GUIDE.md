# Editorial guide

## Add an article

Open `/login`, sign in, choose **Articles**, and select **New article**. Complete both languages, begin with the direct answer, add the explanation, examples, developer perspective, sources and FAQs. Save as a draft until links and claims are checked. **Publish** makes it public; **Scheduled** requires a future schedule time.

SEO title should be specific and readable at roughly 50–60 characters. SEO description should explain the benefit in roughly 140–160 characters. A cover image should have a clear focal point and useful alternative context in the article copy.

## Add a Signature Update

Choose **Signature updates** for launches, milestones, open-source releases, meaningful learning updates and client announcements that are permitted to be public. These entries use the same source, FAQ, metadata and scheduling controls but appear with Yasamin's signature label.

## Editorial review

- Confirm every factual claim against the linked source.
- Remove repeated background and generic AI prose.
- Keep the direct answer useful on its own.
- Never invent personal testing or an opinion for Yasamin.
- Confirm English and Persian express the same facts naturally.
- Preview the article on mobile and desktop before sharing it.
